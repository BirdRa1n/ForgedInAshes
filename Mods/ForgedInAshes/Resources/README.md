# Resources — 3D models and textures (download separately)

`forgedinashes.unity3d` (the models and textures of every machine) is **not in the repository**: it is built by
Unity from `Art/` and is too large to version. Get it from the **Assets** of the latest
[GitHub release](https://github.com/BirdRa1n/ForgedInAshes/releases) and put it here:

```text
Mods/ForgedInAshes/Resources/forgedinashes.unity3d
```

Without it the mod still loads, but the machines have no models. Developers build it themselves with `fe.bat tudo`
(Unity `FeBuild.BuildAll`, see `docs/en/development.md`).
