# AGENTS.md — `Art/` (models and asset bundle)

Read the [root AGENTS.md](../AGENTS.md) first.

## Layout

- `Art/<block>/hd/<block>_HD.blend` — the textured model the game uses; `<block>_HD.fbx` is exported from it.
- `Art/<block>/hd/<block>_src.blend` — geometry source; the texturing step regenerates `_HD.blend` from it.
- `Art/feHD/`, `Art/feKinetic/`, `Art/feConveyor/` — model builders and icon renderers (Blender Python).
- `Art/UnityProject/` — Unity 2022.3.62f2 project. `Assets/Editor/FeBuild.cs` turns the FBX files into prefabs and
  builds `Mods/ForgedInAshes/Resources/forgedinashes.unity3d`. Only `Assets/Editor`, `Packages` and
  `ProjectSettings` are versioned.

## Pipeline

```powershell
fe.bat modelos -Modelos feSteamEngine   # .blend -> FBX -> Unity bundle, for the named model
fe.bat icones  -Modelos feSteamEngine   # inventory icon
fe.bat site    -Modelos feSteamEngine   # GLB for the website
```

## Rules

- Model origin on the floor, block centred; one Blender unit = one block. The root object of `_HD.blend` must keep
  **location and rotation at zero** — an accidental rotation shows up tilted in game (it happened to
  `feSteamEngine`).
- Named children drive behaviour in code: `FeSpin*` (rotating parts), `FeFx_*` (particles), `FePour*` (metal
  streams), `FeSurface_*` (fluid levels), `FeNeedle_*` (gauges), `WireOffset` (power wire anchor). Keep the names.
- Colliders are generated by `FeBuild.cs` from the renderers and kept inside the block's own cells.
- Only original models and textures. Never import game assets.
- After a model change, check it in game (and look at the icon) before committing the bundle.
