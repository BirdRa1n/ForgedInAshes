## Convenciones de esta documentación

- **UT** — unidades de torque. Una máquina *consume* UT; una fuente *ofrece* UT.
- **RPM** — velocidad de giro de una red de ejes. La mayoría de las máquinas trabaja a **32 RPM**.
- **L/min** — caudal de fluido. **bar** — presión de gases y vapor.
- **W** — electricidad del juego (vatios).
- *Mantener E* — mantener pulsada la tecla de **interacción** para abrir el menú radial del bloque; *pulsar E*
  ejecuta su primer comando.
- El mod todavía no tiene traducción al español dentro del juego, así que los bloques y objetos aparecen con su
  **nombre en inglés**, tal como los verás en pantalla, y con el ID interno en `código` cuando ayuda, por ejemplo
  **Steam Turbine** (`feSteamTurbine`, turbina de vapor).
