## Conventions used in these docs

- **UT** — torque units. A machine *costs* UT; a source *offers* UT.
- **RPM** — rotation speed of a shaft network. Most machines are rated at **32 RPM**.
- **L/min** — fluid flow. **bar** — pressure of gases and steam.
- **W** — vanilla electricity (watts).
- *Hold E* — hold your **Activate** key to open a block's radial menu; *tap E* runs its first command.
- Block and item names are written as they appear in game (English localization), with the internal ID in
  `code` where it helps, for example **Steam Turbine** (`feSteamTurbine`).

> [!TIP]
> In game, craft the **Engineer's Manual** and use it (left click) to open the **Production Guide**: it shows how
> every item of the game is made, machine by machine.
