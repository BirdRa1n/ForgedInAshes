## Convenções desta documentação

- **UT** — unidades de torque. Uma máquina *gasta* UT; uma fonte *oferece* UT.
- **RPM** — velocidade de giro de uma rede de eixos. A maioria das máquinas trabalha a **32 RPM**.
- **L/min** — vazão de fluido. **bar** — pressão de gases e vapor.
- **W** — eletricidade do jogo (watts).
- *Segurar E* — segurar a tecla de **interação** para abrir o menu radial do bloco; *tocar E* executa o primeiro
  comando.
- Blocos e itens aparecem com o nome do jogo em português e, quando ajuda, o ID interno em `código`, por exemplo
  **Turbina a Vapor** (`feSteamTurbine`).

> [!TIP]
> No jogo, fabrique o **Manual do Engenheiro** e use-o (clique esquerdo) para abrir o **Guia de Produção**: ele
> mostra como cada item do jogo é feito, máquina por máquina.
